# Assassin Reader

一个简洁的浮窗阅读器，支持 .txt 文件。

## 快捷键

| 快捷键 | 功能 |
|---|---|
| `Ctrl+O` | 打开文件 |
| `Ctrl+I` | 打开章节列表 |
| `← / →` | 上一章 / 下一章 |
| `Ctrl+P` | 打开设置 |
| `Ctrl+Shift+H` | 显示 / 隐藏窗口（可在设置中自定义） |
| `Ctrl+U` | 切换正则拆分规则 |

## 高级正则目录解析

你可以通过 `Ctrl+U` 切换位于 `assets/regex/` 目录下的正则表达式规则。

如果正则表达式中包含捕获组 `()`，程序会优先提取括号内的内容作为目录显示的章节名，从而过滤掉多余的匹配条件。
例如 `三国志.txt` 使用：`^三国志卷[一二三四五六七八九十百]+.*?书[一二三四五六七八九十百]+\s*\n\s*\n\s*([^\r\n]+)` 来跨行提取章节名。
